# Snow 노트 테스트 채보

`Assets/Data/SnowNoteTestChart.asset`는 현재 구현된 노트 5종을 연습하고 비교하는
별도 테스트 채보다. 기존 Snow 음원, 보정된 129.992874 BPM / 4박자 / 첫 박
0.233293초를 사용한다. 실제 악기 채보의 전사가 아니라 박자에 맞춘 테스트 패턴이다.
파트 색상은 탭=drum, 홀드=bass, 슬라이드·바나나=synth, 플릭=etc로 구분한다.
모든 파트를 테스트 구간 전체에서 활성화했다.

## 실행

1. `Assets/Scenes/Gameplay.unity`를 연다.
2. Play Mode 진입 전에 `GameplayRoot`의 `GameplaySession > Chart`에
   `SnowNoteTestChart`를 할당한다. 기존 씬의 기본 채보는 변경하지 않았다.
3. Play Mode에서 시작한다. 첫 두 마디는 준비 구간이며 첫 노트는 약 3.926초,
   마지막 노트는 약 121.625초다. 원곡 음원은 자르지 않았으므로 테스트 후 정지한다.
4. 구간 수정·반복 확인은 `Tools > Idiot Tape > 채보 제작 도구`에서 같은 채보를 선택하고
   아래 마디로 이동한다. 자세한 조작은 [채보 제작](CHART_AUTHORING.md)을 따른다.

## 패턴 지도

총 193개: 탭 144, 홀드 14, 슬라이드 18(일반·플릭 종료), 독립 플릭 5, 바나나 12.
각 구간은 4마디이며, 길게 누르는 노트와 다른 입력을 합쳐 최대 두 접촉으로 구성했다.
마디와 시간은 원곡 기준이다.

홀드는 일부러 일찍 떼어 실패·유예를 비교하고, 슬라이드는 전환 시점에 손가락을
바꿔 인계를 확인할 수 있다. 긴 바나나는 중간 이탈 후 재진입하여 체크포인트의
차지와 끝 보너스를 비교한다. 실패를 유도하는 입력은 선택 사항이며 강제 미스 패턴은 없다.
PC의 플릭 보조키는 제스처 방향·속도 검증을 대신하지 않는다.
